# 점진적 과부하 운동 기록 앱 — 설계

## 목적과 이유
헬스 하는 사람(사용자 본인 1명)이 아이폰에서 그날 한 운동의 무게와 횟수를 기록하면, 다음 운동 때 몇 kg으로 해야 하는지 앱이 알려준다. 지금은 사용자가 기억과 감으로 무게를 올리는데, 이를 앱이 규칙으로 대신해 매주 무게가 꾸준히 늘게 하는 것이 목적이다.

## 목표
- 운동을 고르고, 세트별 무게·횟수를 입력해 저장한다.
- 저장하면 그 운동의 **다음 추천 무게**가 자동 계산되어 보인다.
- 운동 추가 시 800개 이상의 전체 목록에서 부위별 선택 또는 검색을 하고, 이미지로 어떤 운동인지 확인한다.
- 세트 완료 시 휴식 타이머가 돈다.
- 인터넷 없이도 헬스장에서 쓸 수 있다.

## 비목표 / 안티골
- 로그인, 서버, 여러 사용자, 클라우드 동기화는 만들지 않는다.
- 앱스토어 배포는 하지 않는다. 사용자 본인 폰에서만 쓴다.
- 식단, 체중, 루틴 자동 생성, 소셜 기능은 만들지 않는다.
- 안티골: 추천 무게가 사용자의 실제 습관과 어긋나서 믿을 수 없게 되는 것. 동작이 되더라도 이러면 실패다.

## 사용자가 확정한 것
- 플랫폼: 본인 아이폰, 앱은 Claude가 제작. 아이폰에서 홈 화면에 추가해 쓰는 웹앱(PWA) 방식에 동의함.
- 화면 3개 + 기록 목록: 오늘 운동 / 세트 입력 / 운동 관리 / 기록(단순 목록). 목업은 `.superpowers/brainstorm/`의 `screens.html` 참고(텍스트 목업과 동일).
- 증량 규칙(사용자 습관을 그대로 옮김):
  - 벤치프레스: 목표 12회, +5kg, 4세트 중 일부(2~3세트)가 12회를 넘기면 다음에 증량.
  - 덤벨 운동: 목표 12회, +2kg.
  - 12회를 못 채우면 같은 무게로 다시 시도하고, 채울 때까지 반복. 무게를 내린 적은 없음.
- 운동 목록: 전체 목록에서 부위별 선택 + 검색, 운동 이미지 표시.
- 운동 이름/부위: 영어와 한국어를 둘 다 보여준다. 영어가 기본이고, 한국어는 사용자가 확인해 볼 용도.
- 휴식 타이머를 넣는다.

## 추천 무게 규칙 (설계 핵심)
운동마다 설정값을 가진다: `목표 횟수`, `증량 폭(kg)`, `기준 세트 수`, `휴식 시간(초)`.

마지막 기록 하나로 다음 추천을 계산한다.
1. 기준 무게 W = 마지막 기록에서 쓴 가장 무거운 무게.
2. 달성 세트 수 = W로 한 세트 중 횟수 ≥ 목표 횟수인 세트의 수.
3. 달성 세트 수 ≥ 기준 세트 수 → 추천 = W + 증량 폭. 아니면 추천 = W.
4. 기록이 없으면 추천 없음. 첫 입력 때 사용자가 시작 무게를 직접 넣는다.

기본값(운동 추가 시 채워짐, 운동마다 수정 가능): 목표 12회, 증량 5kg, 기준 3세트, 휴식 90초. 덤벨류는 증량 2kg을 권장 기본값으로 둔다.

## 화면
- **오늘 운동:** 오늘 고른 운동 목록. 각 줄에 다음 추천 무게. `+ 운동 추가`, `운동 관리`, `기록` 버튼.
- **운동 추가:** 부위 필터, 검색창, 이미지가 붙은 전체 목록. 고르면 오늘 운동에 추가.
- **세트 입력:** 상단에 오늘 추천 무게와 지난번 기록. 세트 줄마다 무게·횟수 입력(추천 무게가 미리 채워짐). `+ 세트`, `저장`. 세트 완료 시 휴식 타이머 시작.
- **운동 관리:** 운동별 설정값 수정, 새 운동 추가, 백업 내보내기(및 가져오기).
- **기록:** 날짜별 지난 기록의 단순 목록.

## 제약
- 서버 없음. 기록은 폰 안(브라우저 저장소)에 저장. 사파리 데이터를 지우면 사라지므로 백업 내보내기/가져오기가 필수.
- 오프라인 동작. 운동 데이터와 이미지를 앱에 포함한다.
- 운동 데이터 출처: free-exercise-db (Unlicense, 퍼블릭 도메인, 800개 이상, 이미지 포함).
- Windows PC에서 개발, 맥 없음. iOS 네이티브 앱은 불가.

## Claude의 판단 (사용자가 직접 정한 것이 아님, 검토 필요)
- 웹앱은 빌드 도구 없이 순수 HTML/CSS/JS로 만든다. 프레임워크를 쓰지 않는다.
- 배포는 GitHub Pages(무료).
- 기록은 `localStorage`에 JSON으로 저장.
- 오프라인은 서비스 워커로 구현. 이미지는 운동당 첫 번째 이미지 한 장만 포함해 용량을 줄인다. 전체 용량이 크면 구현 단계에서 조정.
- "12회를 넘긴 세트"를 **12회 이상**으로 해석한다. 기준 세트 수 기본값은 3(사용자가 "2~3세트"라 해서 3으로 둠)이고 바꿀 수 있다.
- 기준 무게는 마지막 기록의 가장 무거운 무게로 한다(세트마다 무게가 다를 때를 위해).
- 한국어 운동 이름·부위는 Claude가 번역한다. 어색한 번역이 있을 수 있어 화면에 영어와 함께 표시하고, 사용자가 확인한다. 검색은 영어·한국어 모두 가능.
- 타이머 기본 90초, 운동별로 변경 가능. 세트 완료 시 자동 시작.
- 아이폰 사파리는 웹앱의 진동 API를 지원하지 않을 가능성이 높다. 소리와 화면 표시로 알린다. 화면 꺼짐 방지(Wake Lock)는 시도하되, 아이폰에서의 동작은 실제로 써 봐야 확인된다.
- 단위는 kg 고정. 소수점(예: 2.5kg) 입력은 허용.
- 앱 화면 언어는 한국어.

## 구현자에게 맡기는 것
- 파일 구조, 정확한 디자인(색, 글꼴, 간격), 아이콘, 데이터 변환 방식.
- 이미지 용량 최적화 방법.
- 테스트 방식. 추천 무게 규칙은 단위 테스트로 검증하는 것을 권장.
